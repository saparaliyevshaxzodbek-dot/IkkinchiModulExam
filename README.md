# C# Module 2 — Exam: Movie Catalog

Exam project for the OOP module: a movie catalog with a clean service layer.

## What's inside

- `Movie` model with `MovieCreateDto`, `MovieGetDto` and `MovieUpdateDto`
- `IMovieService` / `MovieService` — create, read, update and delete
- `MovieExtension` — mapping between the model and the DTOs

## Tech

C# · .NET console · OOP

## Run

Requires the .NET SDK.

```bash
cd 2chiExam/2chiExam
dotnet run
```
